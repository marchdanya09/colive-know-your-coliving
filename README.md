# 🏢 CO:LIVE — Платформа чергувань для колівінгів

Універсальний Telegram-бот та Mini App (Web App) для організації побуту, ротації чергувань та підтримки порядку в колівінгах міста.

---

## ✨ Основні можливості

- **🏙 Мульти-колівінг (Multi-tenancy):**
  - Обслуговує довільну кількість різних колівінгів міста з повною ізоляцією даних.
  - Гнучка кількість кімнат (від 1 до 50) та мешканців (до 50 осіб).
- **👑 Кабінет Сотника (Адміністратора):**
  - Швидка реєстрація нового колівінгу за 4 кроки (Назва, Адреса, К-ть людей, К-ть кімнат).
  - Схвалення мешканців через розділ **«📥 Вхідні запити»** з картками кандидатів (`[Схвалити ✅]`, `[Відхилити ❌]`, `[Заблокувати 🚫]`).
  - Генерація єдиного посилання та коду запрошення для мешканців.
  - Кнопка «Стоп-кран» (`🔒/🔓 Перемкнути прийом заявок`) для захисту від спаму.
  - Миттєва ротація коду колівінгу при його компрометації.
- **🙋‍♂️ Кабінет Мешканця (5 головних кнопок):**
  - 📅 **Календар чергувань** — графік поточної чергової кімнати та ротація на 4 тижні вперед.
  - 🚪 **Моя кімната** — склад кімнати, контакти сусідів, кнопка **«✉️ Написати своїй кімнаті»** (миттєва розсилка в ЛС сусідам).
  - 📋 **Мої обов'язки** — структурований чек-лист прибирання (кухня, санвузли, сміття).
  - 🚨 **Термінові скарги** — фотофіксація бруду: бот автоматично надсилає фото в ЛС усім мешканцям чергової кімнати та публікує його в груповий топік з відмітками чергових.
  - 💰 **Штрафи** — баланс спільної скарбнички колівінгу, особисті штрафи та штрафи кімнати.
- **💬 Інтеграція з групою та Топіками:**
  - Прив'язка групи командою `/link_group <КОД>`.
  - **Тегування кімнати одним тегом:** команди `/room1`, `@room1` або `!кімната1` у груповому чаті автоматично викликають згадку всіх мешканців цієї кімнати.
  - Щотижневе автоматичне нагадування щопонеділка о 09:00 у топік «Чергування».
- **🛡 Захист від спаму та DDoS:**
  - 8–10-символьні надійні коди колівінгу (змішаний регістр та цифри).
  - Блокування перебору: 30 невдалих спроб введення коду ➔ бан на 5 хвилин.
  - Ліміт подачі термінових скарг: 1 скарга на 5 хвилин від користувача.
  - Ліміт розсилок по кімнаті: не частіше 1 разу на 1 хвилину.
  - Черга очікування до 30 одночасних заявок.
- **📱 Telegram Mini App (Web App):**
  - Стильний адаптивний інтерфейс на Tailwind CSS із підтримкою теми Telegram.
  - Інтерактивний календар, картки кімнат, перевірка скарбнички та панель сотника.

## 🚀 Швидкий запуск

### 1. Клонування та налаштування оточення
```bash
cd Coliving
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Створення файлу змінних `.env`
Скопіюйте приклад та заповніть токен бота від [@BotFather](https://t.me/BotFather):
```bash
cp .env.example .env
```
Відкрийте `.env` і вкажіть:
```env
BOT_TOKEN=1234567890:AA...
WEBAPP_BASE_URL=https://your-ngrok-or-domain.app
```

### 3. Запуск проекту
```bash
python3 run.py
```

Бот автоматично ініціалізує базу даних `colive.db`, запустить Telegram-бота та підніме Web App API на порті `8000`.

## 🛠 Структура проекту

```text
Coliving/
├── bot/
│   ├── handlers/
│   │   ├── start.py          # Онбординг сотника та мешканців, вхід за кодом/лінком
│   │   ├── user_menu.py      # 5 розділів меню мешканця + розсилка по кімнаті
│   │   ├── sotnik_panel.py   # Вхідні запити, додавання мешканців, стоп-кран, ротація
│   │   └── group_chat.py     # Тегування кімнат у групі, топіки форуму, /link_group
│   ├── keyboards/            # Головна клавіатура та інлайн-кнопки
│   ├── middlewares/          # Антифлуд та захист від спаму
│   └── scheduler.py          # Щотижнева ротація чергувань (щопонеділка 09:00)
├── webapp/
│   ├── templates/index.html  # Telegram Mini App (Tailwind CSS + JS SDK)
│   └── api.py                # FastAPI endpoints для Mini App
├── database/
│   ├── models.py             # Схеми SQLAlchemy (Coliving, Room, User, Duty, Fine, etc.)
│   ├── crud.py               # Операції з базою даних
│   └── db.py                 # Асинхронне підключення SQLite
├── config.py                 # Налаштування та ліміти системи
├── texts.py                  # Всі тексти та повідомлення українською мовою
├── run.py                    # Єдина точка запуску
└── requirements.txt
```
